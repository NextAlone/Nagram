## New

- Communities: new setting for what happens when you tap a community avatar — always open the community, always jump into the chat, or open the community page only when tapping the arrow at the bottom right.
- Communities: new toggle to disable community chat grouping.
- Translation: new "Keep formatting" option that preserves bold, italic and other formatting of the original text.
- Passkeys: sessions and passkeys can now be exported and imported via QR code, so you can sign in on another device by scanning.
- Settings: accounts can now be reordered by dragging.
- Chat settings: new "Ask before sending GIF" and "Ask before sending sticker" toggles that show a confirmation dialog.
- Chat settings: new "Always send videos in HD" toggle.
- Chat settings: new "Global disable link previews" toggle.
- Chat settings: new "Hide side share button" toggle.
- Experimental settings: new "Show icon instead of channel alias" toggle.
- Dialogs: added a "My Profile" entry to the options menu.
- Added support for sign v3.

## Fixes

- Forums: typing indicators now show in every topic of a group instead of only the last one.
- Translation: fixed auto-translate cancelling existing tasks and translation continuing after the page was destroyed.
- Message settings preview: channel avatars are no longer blurry.
- Profile: registration date estimation now uses the Nnngram table, and new accounts show the registration date in the local timezone.
- Settings search: fixed the LOC_ERR localization error during search.
- Proxy: fixed automatic proxy switching not working.
- Proxy: fixed the share button in the proxy list.
- Calls: fall back to a plain call notification when CallStyle is rejected, and restore call vibration on Android 13 and above.
- Monet themes: fixed the unregistered overlay receiver, refreshed Monet colors, and restored the stock theme styling.
- Interface: search header keeps its background under Material Design 3, switches regain their icons, and empty lists in the group creation screen show proper touch feedback.
- Stability: fixed possible null pointer crashes when rebuilding the regex filter cache, reading emoji theme preview colors, and processing child views in themes.
- Stability: fixed the AI feature on ColorOS 17 and the text field animation glitch on some ColorOS devices.
- Stability: fixed localization loading across multiple namespaces and the Nagram localization file failing to load.
- Localization: remaining user-visible NekoX names replaced with Nagram, and a fixed comma separator is used when number rounding is disabled.
