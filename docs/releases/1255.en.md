## New

- Experimental settings: new "Use system notification color" toggle for the notification icon; a restart is required after changing it.
- Rich messages: long-press a downloaded document in a rich message to delete the downloaded file from the options menu, with a confirmation dialog.

## Fixes

- Profile: the stories tab is no longer shown on the profile page when stories are disabled.
- Rich messages: deleting a downloaded file now falls back to the non-cache path, so it works when the file is missing from the cache directory.
- Video: fixed video scaling overflowing the screen in landscape by using the container's actual measured height.
- Calls: audio is routed through communication devices on Android 12 and above, adding support for LE Audio headsets.
- Network: fixed an off-by-one error in tgnet's FakeTLS GREASE generation that caused duplicate ClientHello extension types.
- Localization: removed the deprecated unofficial language packs (moecn, taiwan, ja_raw) and synced the latest Crowdin translations.
