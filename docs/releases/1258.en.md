## New

- Group management: in a supergroup, long-press a member's avatar or a mention in a message, or act from the member list, to open the Change Permissions / Ban or Delete Messages panel right away, even when the member's messages are already gone. Each entry point has its own toggle, off by default.
- Wallet: wallet addresses can now be opened in a blockchain explorer from the options menu of the wallet send screen.
- Settings: folder tabs, double-tap action and the action bar now have live previews, so changes are visible immediately.
- Stickers: new sticker shape setting.
- QR codes: the QR glass effect now follows the "Disable glare effects" setting.
- Interface: larger emoji size; font size and bubble radius are restored to the stock defaults, which previously left new installs with a smaller font and nearly square bubbles.
- Build: native code is now compiled by Gradle, so a fresh clone builds with the submodules and gradlew alone, and CI no longer needs a separate native job.

## Fixes

- Rich messages: photos inside rich text messages now respect protected content and the private-chat "Disable Sharing" setting, hiding "Save to Gallery" and other entries and enabling the secure flag.
- Privacy: with "Disable Sharing" enabled in a private chat, long-pressing to select text no longer offers Copy or Select All.
- Sharing: fixed sharing multiple files from other apps failing entirely because scoped storage could not read the resolved paths; files multi-selected in the system picker are now sent as a single album instead of one by one, and a group whose last file fails is sent with the files already queued.
- Bot forums: updateMessageID is read before processing updates when creating a topic, so the typed or forwarded message lands inside the new topic instead of outside it.
- Chats: the system Back button is no longer ignored while a bot keyboard is persistent.
- Instant View: links opened from Instant View now respect the in-app browser settings and per-domain exceptions instead of always using the in-app browser.
- Profile: the channel-only "Set as Main Tab" option is no longer shown for supergroups, and gift reordering no longer shifts the gifts.
- Login: the email code and two-step verification email screens show the localized "Email not allowed" message instead of a generic error.
- Groups: your own participant info is loaded automatically when the member list hides participants, so it is no longer missing from the shared media lists.
- Interface: the chat list no longer keeps an empty strip at the bottom when the main tabs are disabled, and a restart is suggested after changing the tab style.
- Language: each suggested language is offered only once, so toggling a proxy no longer brings the prompt back, and it is skipped if you picked a language yourself or use a custom language pack.
- Communities: a community opened as a chat no longer shows the stories row when only your own stories are active, so its avatar no longer overlaps the action bar.
- Messages: reverted the automatic comma after mentions.
- Localization: synced the latest Crowdin translations.
